About

I like making deployments boring.

I am a DevOps engineer who builds pipelines that test and ship code automatically, packages applications in containers, and describes infrastructure as code so any environment can be rebuilt from a single repository.

I keep things small and documented: short pipelines, clear READMEs, and changes that can be reviewed and rolled back.
